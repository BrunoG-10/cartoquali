# Checklist interno do MVP

- [x] Dados exclusivamente em memória, sem persistência ou backend.
- [x] Contratos centrais tipados e fronteira mock → API documentada.
- [x] Escopo por cartório em listagens e operações principais.
- [x] URL pública valida cartório e ponto.
- [x] Avaliação anônima, contato opcional e consentimento explícito.
- [x] Indicadores compartilhados entre Dashboard, Qualidade e Relatórios.
- [x] Taxa negativa e quantidade negativa diferenciadas no contrato.
- [x] Filtros e comparação do período anterior centralizados.
- [x] Histórico de relatórios disponível na sessão e com filtros registrados.
- [x] Mensagens de validação integradas, sem alerta nativo.
- [x] Mocks verificados para IDs duplicados e vínculos condicionais.
- [x] Documentação funcional, técnica e de backend futuro.
- [ ] Revalidar os cenários no navegador após cada mudança relevante.
